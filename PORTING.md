# Porting record

kalyx is built from its foundations. Some of its code is taken over from
two sources, and this record lists all of it, added in the same change as
the code:

- foundation code of an earlier implementation of the casξ computer algebra
  system, which is not public, written as
  `cas-project@<full commit SHA>:<path>`, where `cas-project` names the
  earlier implementation;
- the proof tooling of [krepi](https://github.com/casxi-lab/krepi), the
  kernel of casξ, written as `krepi@<full commit SHA>:<path>`. krepi took
  parts of this tooling over from the earlier implementation; the rows of
  those parts also name the commit of the earlier implementation that they
  come from.

There is one row per module or file taken over. The test files of a module
are in its row, and the fixture directory of the proof tooling, the
qualification crate and the directory of external declarations take one row
each.

- **Module**: the module or file in this repository.
- **Source**: the files it came from.
- **Change**: one of *ported* (taken over with only the changes that the
  rules of this repository require), *adapted* (interfaces or structure
  changed) or *fixed deviation* (a known deviation of the source from its
  contract was corrected, with a test that rejects it); a short note follows
  and names any known deviation that is kept as a limitation. A file of the
  proof tooling ported *byte for byte* is the krepi file unchanged; one
  ported *with the names of kalyx* is the krepi file with the replacements
  of [names](#names) and no other change.
- **Tests not carried over**: tests of the source that were not taken over,
  one per line, each with the reason.

Ported code is tested again in this repository. Tests, proofs and results of
the earlier implementation and of krepi are not evidence for kalyx.

## Names

The proof tooling names krepi in its Lean namespaces, paths, environment
variables, messages and comments. A file ported with the names of kalyx
replaces every `krepi`, `Krepi` and `KREPI` by `kalyx`, `Kalyx` and `KALYX`,
which keeps the length of every line:

| In krepi | In kalyx |
| --- | --- |
| `Krepi`, the root namespace and directory of the Lean project, as in `Krepi.Proofs` and `verification/Krepi/`, and in `KrepiRoot` and `KrepiVectorsReplay` | `Kalyx`, `Kalyx.Proofs`, `verification/Kalyx/`, `KalyxRoot`, `KalyxVectorsReplay` |
| `KrepiGen`, the namespace of the generated definitions | `KalyxGen` |
| `krepiVerification`, the name of the Lake package | `kalyxVerification` |
| `krepi-audit`, the marker of the lines of the audit output, and `krepi-xtask-`, the prefix of the names of scratch directories | `kalyx-audit`, `kalyx-xtask-` |
| `KREPI_`, the prefix of environment variables, and `KREPI` | `KALYX_`, `KALYX` |
| `krepi` in descriptions, comments, messages and test data | `kalyx` |

Three strings are not replaced: the name of the proof-tool image,
`ghcr.io/casxi-lab/krepi-formal`, its path `/opt/krepi-formal` in the image,
and the notation `krepi@` of a source.
