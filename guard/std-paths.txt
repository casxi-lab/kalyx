# The std paths that the non-test code in src/ may use, checked by the guard
# step of `cargo xtask check`.
#
# One entry per line; blank lines and lines that start with `#` are skipped.
# An entry is a path of at least two segments. It permits a path that equals
# it or lies below it: `std::fmt` permits `std::fmt::Display`, and
# `std::io::Write` permits `std::io::Write::flush` but not other names that
# merely start with `Write`. The guard checks every path that starts with
# `std` in a `use` declaration, an expression, a type, a pattern, a macro or
# an attribute; a `use` tree is expanded first, and a glob such as
# `use std::fmt::*;` names its module, `std::fmt`. Importing a module, as in
# `use std::io;`, therefore needs the module itself in this list.
#
# Never listed, and rejected by the guard even if listed: std::thread,
# std::thread_local, HashMap, HashSet and the rest of hash_map and hash_set,
# RandomState, SystemTime, UNIX_EPOCH and catch_unwind. Extending this list
# is a reviewed change of its own.
